# За нами дім — лендінг

Статичний лендінг спільного збору 2-го корпусу НГУ «Хартія» та групи «Нафтогаз».
Без збірки й залежностей: просто HTML + CSS + JS, хоститься на GitHub Pages.

## Структура

```
index.html              — сторінка
assets/style.css        — стилі
assets/main.js          — логіка відеоплеєра і липкої кнопки
assets/img/             — логотипи, фото, og.jpg (прев'ю для соцмереж)
assets/video/poster.jpg — кадр-заставка відео (показується миттєво)
assets/video/preview.mp4— коротке беззвучне прев'ю (~1–2 МБ, грає по колу)
assets/video/full.mp4   — повне відео (вантажиться лише після кліку)
.nojekyll               — вимикає обробку Jekyll на GitHub Pages
```

## Що змінювати

- **Посилання на банку** — шукай `send.monobank.ua/jar/7jnQhBXhYW` в `index.html` (4 місця).
- **Тексти** — прямо в `index.html`, блок `<!-- ОПИС + КНОПКА -->`.
- **Відео** — заміни файли в `assets/video/` з тими самими назвами.
